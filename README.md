## `>_` CONTRIBUTION SNAKE

<div align="center">

<img src="https://raw.githubusercontent.com/biaramoxx/biaramoxx/output/github-contribution-grid-snake-dark.svg" alt="snake animation"/>

</div>

<details>
<summary><sub>⚙️ Como ativar a animação da cobra (clique para expandir)</sub></summary>

<br/>

1. Crie o repositório especial `biaramoxx/biaramoxx` (mesmo nome do seu usuário) — se ainda não existir.
2. Dentro dele, crie o arquivo `.github/workflows/snake.yml` com o conteúdo:

```yaml
name: Generate Snake Animation
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch: {}
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: biaramoxx
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Rode o workflow uma vez em **Actions → Generate Snake Animation → Run workflow**.
4. A imagem passa a ser gerada automaticamente todos os dias.

</details>
